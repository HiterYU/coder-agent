# Your Skill

## 写作原则

- 只写该 Agent 完成本任务所需的专门流程、领域知识和输出约束。
- 保持简洁，默认模型已经具备通用推理能力。
- 把触发条件写进 front matter 的 `description` 和 `keywords`，不要只写在正文。
- 如果规则与本次任务指令冲突，正文应说明哪一类约束优先。

## 建议结构

1. 工作流程：按执行顺序列出 3-6 步。
2. 输入使用：说明必须读取哪些上下文字段，哪些字段只能作为辅助证据。
3. 输出契约：列出必须输出的字段、格式和语言。
4. 质量门槛：列出必须检查的正确性、边界或安全要求。
5. 兜底策略：说明上下文不足、工具失败或不确定时如何回答。

## 示例骨架

- 只输出中文 JSON，不输出 Markdown。
- 必须先检查 `...`，再生成 `...`。
- 不得编造输入中不存在的事实。
- 如果证据不足，明确说明缺少什么，并给出下一步可执行动作。
